Screen Time Authorization

Nunc needs Apple Screen Time authorization to block one to three selected apps, websites, or categories. If access is denied before a block starts, return to Choose distractions and confirm Screen Time access. If access changes during an active Study Block, choose Restore Screen Time access. Nunc keeps the task, selected distractions, Study Block boundary, task start time, and completed-task count while it attempts to reapply the same block. Apple controls whether the authorization prompt appears again.

Blocking Did Not Start

A healthy active block says Blocking is on. Technical details are optional. If blocking did not start or automatic ending may not work, choose Try again when it appears. Nunc may also retry the same saved block once after relaunch. Trying again preserves the task, selection, Study Block ID, deadline, task start time, Study Mode, commitment setting, and completed-task count; it does not start a new block or reset progress. If Screen Time access is unavailable, use Restore Screen Time access instead.

Website Coverage

Website blocking depends on Apple's Screen Time coverage and can vary by browser, website, and device state. Nunc does not claim reliable coverage for every browser or website.

Ending Blocking Early

A Standard Study Block offers a deliberate early-ending action and records when blocking ends early. A timed Study Block using Pro's optional No early ending setting does not offer Nunc's in-app early-end action before the displayed deadline. Task completion, same-deadline task chaining, and technical recovery remain available. No early ending is not a claim that blocking is unbreakable.

Purchases And Restore

Subscriptions are processed by Apple. Use Restore Purchases on the Nunc paywall when an active subscription is not recognized. Manage or cancel subscriptions in your Apple Account subscription settings.
